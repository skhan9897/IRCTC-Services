Login ka actual flow login.html ↓ Email + Password ↓ POST /api/auth/login ↓ AuthController ↓ AuthService ↓ UserRepository ↓ MySQL ↓ Login Response ↓ localStorage ↓ dashboard.html Tumhare current "AuthService" ke response ke according ye fields save hongi: userId name email role Isliye dashboard mein "userId" mil jayega aur ye API automatically kaam karegi: GET /api/users/{userId} GET /api/bookings/user/{userId} Important: Login page tabhi successfully authenticate karega jab "PasswordEncoder" ka Spring bean configured ho.
